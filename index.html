00 / REPASO

Las cuatro herramientas

Cada ejercicio combina estos cuatro conceptos. Tenelos a mano mientras trabajás.

Error absoluto
Ea = |xᵥ − xₐ|
Diferencia entre el valor verdadero y el aproximado. Mismas unidades que la magnitud.
Error relativo %
Er = (Ea / |xᵥ|) × 100
Adimensional. Permite comparar precisión entre mediciones de distinta escala.
Serie de Taylor
Pₙ(x) = Σ f⁽ᵏ⁾(a)/k! · (x−a)ᵏ
Aproxima f cerca de x=a. El residuo de Lagrange Rₙ acota el error de truncamiento.
Propagación
Δy ≈ |f'(x)| · Δx
Cómo la incertidumbre de una medición de entrada se traslada a una magnitud calculada.
